# SOMRAT CYBER LOOKUP

A Python-based public information lookup and personal digital safety toolkit.

## FEATURES

- Number Intelligence
- Public Profile Search
- Scam Threat Scan
- Evidence Collection
- Link Safety Analysis
- Own Call Log Analysis
- WhatsApp Public Information Lookup
- API Configuration

## REQUIREMENTS

- Android
- Termux
- Python 3
- Git
- Internet Connection

## INSTALLATION

Update packages:

    pkg update && pkg upgrade -y

Install Git and Python:

    pkg install git python -y

Clone repository:

    git clone https://github.com/somrat3376-sys/SCL.git

Open project:

    cd SCL

Install dependencies:

    python -m pip install -r requirements.txt

## RUN TOOL

    python main.py

## UPDATE TOOL

Open project directory:

    cd SCL

Download latest updates:

    git pull

Install updated dependencies:

    python -m pip install -r requirements.txt

Start tool:

    python main.py

## API CONFIGURATION

Some integrations may require API keys from their official providers.

- Use official API credentials only.
- Never publish API keys or passwords.
- Never upload private credentials to GitHub.

## PRIVACY AND SAFETY

- Use public information responsibly.
- Access only data you own or are authorized to use.
- Import only your own call logs or authorized records.
- Do not attempt unauthorized access to private accounts.
- Independently verify lookup results.
