# SOMRAT CYBER LOOKUP

A Python-based public information lookup and personal digital safety toolkit.

## FEATURES

- Number Intelligence
- Public Profile Search
- Scam Threat Scan
- Evidence Collection
- Link Safety Analysis
- Own Call Log Analysis
- WhatsApp Public Information Lookup
- API Configuration

## REQUIREMENTS

- Android
- Termux
- Python 3
- Git
- Internet Connection

## INSTALLATION

Update Termux:

    pkg update && pkg upgrade -y

Install Git and Python:

    pkg install git python -y

Clone the project:

    git clone https://github.com/somrat3376-sys/SCL.git

View downloaded projects:

    ls

Open SCL project:

    cd SCL

View project files:

    ls

Install dependencies:

    python -m pip install -r requirements.txt

## RUN TOOL

Start SOMRAT CYBER LOOKUP:

    python main.py

## UPDATE TOOL

    cd SCL
    git pull
    python -m pip install -r requirements.txt
    python main.py
